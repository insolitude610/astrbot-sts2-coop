## 1. 今天到底做成了什么

### 1.1 修掉原版插件的 8 个缺陷

原版 `astrbot_plugin_sts2_player v0.4.8` 是**单人局**打磨的，双人联机下逐个暴露：

| # | 缺陷 | 原版表现 | 实测证据 |
|---|---|---|---|
| D1 | 地图投票后 `RuleBot._map()` 返回 `None` | **整局停下** | 发 `/sts2 自动` 只回「不知道地图该做什么」 |
| D2 | 瞬时过期快照当硬错误 | 累计 3 次停机 | **0s 重试必败，0.15s+ 基本成功**（18 次试验） |
| D3 | 结束回合后误判为「敌方回合」 | 空转到 600 次上限 | `local_ready_to_end_turn=True` 被忽略 |
| D4 | `status=pending` 当已完成 | 读到旧界面 | 引擎回「Action queued but state is still transitioning」 |
| D5 | 事件未用 `will_kill_player` | **打到 1/1 HP** | 75HP 被一路扣光，遗物加分盖过掉血惩罚 |
| D6 | 后端识别永久缓存 | **404 Route not found** | 先开 AstrBot 后开游戏 → `_mode` 锁死成 mcp |
| D7 | 已投票仍重复投票 | **3.2 秒投 9 次** | `available_actions` 里动作不消失（允许改票） |
| D8 | 播报条件永远不成立 | **全程零回复** | `i % 15 == 0 or i == steps`，steps=10 时两个都不成立 |

### 1.2 新增的四个交互能力

| 功能 | 触发 | 说明 |
|---|---|---|
| **聊天注入战况** | 自动 | `on_llm_request` 注入临时块，游戏关掉时零注入 |
| **后台托管** | `/sts2 托管` | 常驻循环，一次指令一直打 |
| **自然语言触发** | 私聊说「有牌打」 | 关键词可配置，群里不生效 |
| **AI 主动询问** | 卡住 60 秒 | 模型结合最近聊天记录生成，不是固定模板 |

## 4. 怎么用

### 4.1 起一局

```powershell
$g = "<GAME_DIR>"

# 1. 主窗口（你自己玩）
Start-Process "$g\SlayTheSpire2.exe" -ArgumentList '-fastmp','host_standard' -WorkingDirectory $g

# 2. 等主窗口稳定 35 秒以上（少了会握手超时！）
Start-Sleep -Seconds 38

# 3. 队友实例
$env:STS2_MULTIPLAYER_HOST_IP = '127.0.0.1'
$env:STS2_MULTIPLAYER_NET_ID  = '<未用过的数字>'
$env:STS2_API_PORT            = '8082'
$env:STS2_API_ALLOW_FALLBACK  = '1'
$env:STS2_AGENT_ROLE          = 'companion'
$env:STS2_AGENT_AUTOPLAY      = '0'
$env:STS2_AGENT_SETTINGS_PATH = "$env:APPDATA\STS2AIAgent\settings.companion.json"
Start-Process "$g\SlayTheSpire2.exe" `
  -ArgumentList '--windowed','--force-steam','off','--clientId','<同上>','-fastmp','join' `
  -WorkingDirectory $g
```

**新 clientId 必须预置存档**（否则 mod 不加载、队友没 API）：

```powershell
# 先启动一次让它生成目录，立刻关掉进程，再改：
$p = "$env:APPDATA\SlayTheSpire2\default\<clientId>\settings.save"
#   "mod_settings": null  → 开启 STS2AIAgent
#   "seen_ea_disclaimer": false → true
#   "skip_intro_logo": false → true
```

### 4.2 在 QQ 里用

| 你说 | 效果 |
|---|---|
| 「有牌打」/「帮我打」/「打吧」 | **启动托管，之后一直打** |
| 随便闲聊 | bot 知道战况，正常回复；托管**暂停 6 秒**后自动继续 |
| 卡住 60 秒 | bot 主动问一句（模型生成，会接上你们刚才聊的） |
| `/sts2 状态` | 看当前局面 |
| `/sts2 停止托管` | 停 |
| `/sts2 自动 10` | 只打 10 步（一次性，与托管二选一） |

### 4.3 停止的一切方式

- `/sts2 停止托管` 或 `/sts2 停`
- 对局结束（`game_over`）
- 连续 20 次读不到游戏
- 状态 20 次没变化（死循环保护）
- 连续运行超过 `autopilot_max_hours`（默认 4 小时）

## 6. 环境踩坑（血泪版）

### 6.1 新 clientId 必须手工补 mod 配置

`%AppData%\SlayTheSpire2\default\<id>\settings.save` 新建时是 `"mod_settings": null`，
mod **不加载**，队友没有 API。必须**先启一次生成目录、关掉进程、再改**（运行中改会被覆盖）。

### 6.2 主窗口必须稳定 35 秒以上再拉队友

少了会 `[ENetClient] Timed out waiting for handshake ack!`，并留下**幽灵玩家**：
主机 `connected_player_ids` 里留着那个 id，该 id 永久不能复用，且战斗会永远卡住等它。

**修法**：重启主窗口重建大厅。

### 6.3 主号的 mod 默认是关的

`steam\<id>\settings.save` 里 `STS2AIAgent.is_enabled` 默认 `false`。

### 6.4 两个实例的界面可能不同步

实测出现过主机在 `EVENT`、队友在 `MAP`。这是联机语义，不是 bug，但**驱动脚本不能假设两边一致**。

### 6.5 双人局敌人血量约 2 倍

例：小啃兽 99HP（`base_max_hp: 45`）。

### 6.6 PowerShell 来回写文件会毁编码

用 `Set-Content` 改带中文的 `.py` 会造成 `SyntaxError: unterminated string literal`。
**改文件用 `write`/`edit` 工具，别用 PowerShell 文本重写。**

### 6.7 git 提交信息含引号会炸

`git commit -m "..."` 里带 `"` 或行内代码会被 PowerShell 解析。
**用 `git commit -F <文件>`。**
